Which games are solved, by whom, how strongly, and what is left. Each entry
gives the result, the strength of the solution, the size of the search space,
who solved it and when, and the sources.

## How it works

<CardGrid>
	<Card title="One record per game" icon="open-book">
		Every page is generated from one YAML file holding the result, the solution
		strength, the search-space size, who solved it and when, and the citations,
		so the tables and the pages always agree.
	</Card>
	<Card title="What's still open" icon="puzzle">
		Board sizes and variants that remain unsolved, each with the best published
		partial result and the next step.
	</Card>
	<Card title="Corrections welcome" icon="pencil">
		Missing a game, a citation, or a wrong result? Each entry is one YAML file:
		open an issue or a pull request.
	</Card>
</CardGrid>
